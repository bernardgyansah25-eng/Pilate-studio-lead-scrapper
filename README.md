## What This Project Does
Automated n8n workflow that finds Pilates studios, enriches their business data, saves it to Google Sheets, and sends outreach emails.

## How It Works
1. **Schedule Trigger** - Runs automatically
2. **Search** - Finds studios via API
3. **Code (JavaScript)** - Cleans data: Name, Address, Website, Phone, Rating
4. **HTTP Request** - Visits each website to enrich data
5. **Google Sheets** - Saves all leads in a sheet
6. **Gmail** - Sends personalized outreach email

## Tools Used
- n8n
- JavaScript
- HTTP Request / API
- Google Sheets
- Gmail

## Privacy Note
Demo uses only publicly listed business information. No private emails or phone numbers are shown.
